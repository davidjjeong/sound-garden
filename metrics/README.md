# Metrics

Recorded experiments and the evidence behind performance claims.

- [Hand-tracking latency and throughput](hand-tracking/README.md): three real-camera
  sessions, original JSON exports, per-run results, and pooled statistics.

- [Concurrent duplicate uploads](concurrent-uploads/README.md): four hosted batches
  with 2, 5, and 10 attempts; database and Storage evidence for one ready track per fixture.

Only reviewed benchmark exports belong here. Save new, unreviewed downloads in
`benchmark-results/`, which is ignored by Git.
